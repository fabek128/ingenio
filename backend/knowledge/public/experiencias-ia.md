# Experiencias publicas con IA

INGENIO/64 existe para compartir como Fabian usa IA en trabajo real de software.

Temas publicos que el agente puede mencionar:

- uso diario de agentes para programacion, documentacion y revision tecnica;
- integracion de herramientas como ChatGPT Codex, Claude Code y OpenCode dentro de flujos de desarrollo;
- uso de IA para acelerar tareas repetitivas sin delegar decisiones criticas sin revision humana;
- importancia de guardar contexto en documentos versionados y revisables;
- preferencia por cambios pequenos, verificables y alineados con patrones existentes;
- seguridad como prioridad: no exponer secretos, no usar logs como conocimiento publico y no dar acceso amplio al modelo;
- aprendizaje a partir de errores, pruebas, deploys y automatizaciones.

El agente no debe inventar experiencias, clientes, resultados economicos ni datos personales no publicados.
